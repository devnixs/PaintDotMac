**Paint.NET 3.36 behavior (transcribed; `ClampToByte(double v)` = `v > 255 → 255; v < 0 → 0; else (byte)v` (truncation); `W`, `H` = layer size; integer `x, y`).**

*JuliaFractalEffect* (`SubmenuNames.Render`): `DoubleProperty(Factor, 4.0, 1.0, 10.0)`, `DoubleProperty(Zoom, 1, 0.1, 50)`, `DoubleProperty(Angle, 0.0, −180, 180)` (angle chooser), `Int32Property(Quality, 2, 1, 5)`. `angleTheta = angle·2π/360`.
```
Julia(x, y, r, i):          // r = 0.3125, i = 0.03
    c = 0.0
    while c < 256 && x*x + y*y < 10000 { t = x; x = x*x − y*y + r; y = 2*t*y + i; ++c }
    c −= 2 − 2*log2_10000 / ln(x*x + y*y)        // log2_10000 is ln(10000) despite its name
    return c
OnRender: invH = 1/H; invZoom = 1/zoom; invQuality = 1/quality; aspect = H/W; count = quality² + 1; invCount = 1/count
  per pixel: r = g = b = a = 0 (int)
    for i in 0..<count (i is a double):
        u = (2x − W + i·invCount)·invH;   v = (2y − H + ((i·invQuality) % 1))·invH
        radius = √(u² + v²); θ' = atan2(v, u) + angleTheta; uP = radius·cos θ'; vP = radius·sin θ'
        jX = (uP − vP·aspect)·invZoom;   jY = (vP + uP·aspect)·invZoom
        c = factor · Julia(jX, jY, 0.3125, 0.03)
        b += ClampToByte(c − 768); g += ClampToByte(c − 512); r += ClampToByte(c − 256); a += ClampToByte(c)
    dst = (R: r/count, G: g/count, B: b/count, A: a/count)      // integer division; written over the pixel
```
*MandelbrotFractalEffect* (`SubmenuNames.Render`): `Int32Property(Factor, 1, 1, 10)`, `DoubleProperty(Zoom, 10, 0, 100)`, `DoubleProperty(Angle, 0, −180, 180)` (angle chooser), `Int32Property(Quality, 2, 1, 5)`, `BooleanProperty(InvertColors)` (default false; display name empty, description "Invert Colors" = checkbox text). `zoom' = 1 + 20·Zoom`; `xOffset = −0.7`, `yOffset = −0.29`; `max = 100000`, `invLogMax = 1/ln(max)`.
```
Mandelbrot(r, i, factor):
    c = 0 (int); x = y = 0
    while c·factor < 1024 && x*x + y*y < max { t = x; x = x*x − y*y + r; y = 2*t*y + i; ++c }
    return c − ln(y*y + x*x)·invLogMax
OnRender: as Julia for u, v, uP, vP (no aspect); m = Mandelbrot(uP·invZoom + xOffset, vP·invZoom + yOffset, factor)
    c = 64 + factor·m
    r += ClampToByte(c − 768); g += ClampToByte(c − 512); b += ClampToByte(c − 256); a += ClampToByte(c)
    dst = (r/count, g/count, b/count, a/count); if invertColors { R,G,B ← 255 − R,G,B } (alpha kept)
```
Note the swapped channel ramps (Julia: red is the `−256` ramp; Mandelbrot: blue is). Both use the **whole layer** size and center and **overwrite** the pixel (Paint.NET 5 adds a Blend Mode).

## User story

As a Paint.NET switcher, I choose **Effects ▸ Render ▸ Julia Fractal…** or **Mandelbrot Fractal…**, see the fractal appear live in my layer or selection, tune Factor, Zoom, Angle, Quality (and Invert Colors for Mandelbrot) and a Blend Mode, and OK records one "Julia Fractal" / "Mandelbrot Fractal" step. On a layer holding a cut-out object surrounded by transparency, I choose **Effects ▸ Object ▸ Drop Shadow…**, set Shadow Radius, Distance, Angle, Opacity, Color and optionally Only Draw Shadow, and get a soft shadow behind my object; or **Effects ▸ Object ▸ Outline Object…** to draw a Radius-wide outline of a chosen color around it. Each is one undoable step, ⌘F repeats it, and with a selection only selected pixels change. After this spec the Effects menu holds every P0 and P1 effect of PRD §5.9.

### Core (pure, headless, unit-tested)

1. **`PaintDotMac/Core/Effects/Effects/Render/FractalMath.swift`** (new) — the **normative, single-precision definition** of both fractals (*Open questions* 1). Every operation is one IEEE-754 `Float` operation in the order written (no fused multiply-add: write products as separate `let`s; Swift does not contract), constants are computed once in `Double` and rounded to `Float`.
   ```swift
   public enum FractalMath {
       /// Paint.NET's ClampToByte(double) on Float: NaN → 0, v > 255 → 255, v < 0 → 0 (incl. −∞), else Int(v) (truncation); +∞ → 255.
       public static func clampToByte(_ v: Float) -> Int
       public struct Frame: Sendable, Equatable {
           public let originX, originY, width, height: Int   // reference bounds (item 2)
           public let quality: Int, count: Int               // count = quality² + 1
           public let invH: Float                            // Float(1.0 / Double(height))
           public let invCount: Float, invQuality: Float     // Float(1.0 / Double(count)), Float(1.0 / Double(quality))
           public let cosA: Float, sinA: Float               // Float(cos θ), Float(sin θ), θ = angle·π/180 in Double
           public init(bounds: PixelRect, quality: Int, angleDegrees: Double)
       }
       /// Sample i's sub-pixel offsets: sx = Float(i) * invCount; t = Float(i) * invQuality; sy = t − floor(t).
       public static func sampleOffset(_ i: Int, frame: Frame) -> (sx: Float, sy: Float)
       /// Rotated sample coordinates for canvas pixel (x, y), sample i:
       /// xf = Float(x − originX), yf = Float(y − originY), wf = Float(width), hf = Float(height)
       /// u = ((2·xf − wf) + sx) · invH;  v = ((2·yf − hf) + sy) · invH
       /// uP = (u·cosA) − (v·sinA);  vP = (u·sinA) + (v·cosA)          (= 3.36's radius·cos/sin(atan2(v,u)+θ))
       public static func rotated(x: Int, y: Int, sample i: Int, frame: Frame) -> (uP: Float, vP: Float)
       public static let juliaC: (r: Float, i: Float) = (0.3125, 0.03)       // Float literals
       public static let juliaLogConstant: Float = Float(2 * log(10000.0))      // 18.420680743952367 → Float
       public static let mandelbrotInvLogMax: Float = Float(1 / log(100000.0))  // 0.08685889638065035 → Float
       public static let mandelbrotOffset: (x: Float, y: Float) = (-0.7, -0.29)
       /// Julia smooth count: n = 0 (Int); while n < 256 && (x·x + y·y) < 10000 { t = x; x = (x·x − y·y) + 0.3125; y = (2·t)·y + 0.03; n += 1 }
       /// m = x·x + y·y; return Float(n) − (2 − juliaLogConstant / log(m))      (log(1) = 0 → +∞ → 255; log(0) = −∞ → Float(n) − 2)
       public static func juliaValue(x: Float, y: Float) -> Float
       /// Mandelbrot: n = 0; x = y = 0; while n·factor < 1024 && (x·x + y·y) < 100000 { t = x; x = (x·x − y·y) + r; y = (2·t)·y + i; n += 1 }
       /// return Float(n) − log(y·y + x·x) · mandelbrotInvLogMax        (note y·y + x·x, 3.36's order; log(0) → +∞ → 255)
       public static func mandelbrotValue(r: Float, i: Float, factor: Int) -> Float
       /// Per pixel, before blending. Julia: per sample jX = (uP − vP·aspect)·invZoom, jY = (vP + uP·aspect)·invZoom,
       /// c = Float(factor) · juliaValue(jX, jY); sums R += clamp(c − 256), G += clamp(c − 512), B += clamp(c − 768), A += clamp(c);
       /// result (R/count, G/count, B/count, A/count) with integer division.  aspect = Float(Double(height)/Double(width)), invZoom = Float(1/zoom).
       public static func juliaPixel(x: Int, y: Int, frame: Frame, factor: Double, zoom: Double) -> ColorRGBA8
       /// Mandelbrot: per sample m = mandelbrotValue((uP·invZoom) + (−0.7), (vP·invZoom) + (−0.29), factor), c = 64 + Float(factor)·m;
       /// R += clamp(c − 768), G += clamp(c − 512), B += clamp(c − 256), A += clamp(c); integer division by count;
       /// invert → (255 − R, 255 − G, 255 − B, A).  invZoom = Float(1 / (1 + 20·zoom)).
       public static func mandelbrotPixel(x: Int, y: Int, frame: Frame, factor: Int, zoom: Double, invert: Bool) -> ColorRGBA8
   }
   ```
   `juliaPixel`/`mandelbrotPixel` are the Core CPU path used by unit tests and by nothing at run time (the GPU kernels are the product path); the test-target oracles (Test plan) are written independently.

## Edge cases

- **Julia `log(m)` singularities:** `m == 1` → `+∞` → all four channels of that sample 255; `m == 0` → `j = n − 2`; `m < 1` → large negative → 0. NaN never reaches a byte (clamp maps NaN → 0). → `FractalMathTests.clampToByteSpecials`, `.juliaSingularities`
- **Mandelbrot `log(0)`** (orbit exactly at 0, e.g. `r = i = 0` reached only with a rotated grid hitting `(0.7, 0.29)` exactly): `+∞` → 255. Points that never escape stop at `n·factor ≥ 1024` → white opaque `(255,255,255,255)` (inverted: `(0,0,0,255)`). → `FractalMathTests.mandelbrotInteriorIsWhite`, `.mandelbrotLogZero`
- **Iteration bit-exactness on the GPU:** if any fractal pixel differs from the oracle by more than 1, the cause is fused or fast-math arithmetic; fix the pragmas (item 8) — as last resort set `MTL_FAST_MATH: NO` for the app target in `project.yml` and re-run every golden suite — never widen the tolerance. → `RenderV1xGoldenTests.juliaGrid`, `.mandelbrotGrid`
- **Zoom extremes:** Mandelbrot Zoom 0 (`zoom' = 1`), Zoom 100 (`2001`); Julia Zoom 0.1 and 50. Factor 10 (Mandelbrot 103 iterations max), 1 (1024). Quality 1 (2 samples) and 5 (26 samples). → `RenderV1xGoldenTests.juliaGrid`, `.mandelbrotGrid`
- **Tiny and extreme canvases:** 1×1 (`invH = 1`, `aspect = 1`), 1×7, 7×1, 65,535×1 region x ≥ 65,023 (Float coordinates `2x − w` ≤ 131,070 exact). → `RenderV1xGoldenTests.tinyImages`, `.extremeAspect`
- **Fractal over transparent pixels:** Normal over `(0,0,0,0)` = the fractal pixel; a fractal pixel with alpha 0 leaves the layer pixel unchanged (sparse tiles stay unallocated only if every fractal alpha in them is 0). → `RenderV1xGoldenTests.sparseTiles`
- **Empty object layer** (all `(0,0,0,0)`): Drop Shadow/Outline Object output equals the input → no step, no tiles allocated. → `ObjectEffectsIntegrationTests.emptyLayerAddsNoStep`
- **Fully opaque layer** (no transparency, "not an object" per the docs): Drop Shadow without Only Draw Shadow and Outline Object change nothing → no step; Only Draw Shadow turns it into the shadow color at `255·S·k` (interior `S = 1` → alpha 191 at defaults). → `ObjectEffectsIntegrationTests.opaqueLayerNoStep`, `DropShadowReferenceTests.shadowOnlyOpaqueInterior`
- **Zero-strength settings:** Opacity 0 or color alpha 0 without Only Draw Shadow, Outline color alpha 0 → `prepare` `.noChange` → no step, `lastApplied` set. Opacity 0 **with** Only Draw Shadow removes the object (all `(0,0,0,0)`), which is a change. → `DropShadowTests.zeroOpacityIsNoChange`, `OutlineObjectTests.transparentColorIsNoChange`, `DropShadowReferenceTests.shadowOnlyZeroOpacityClears`
- **Shadow falling outside the canvas / object at the canvas edge:** samples outside the canvas are 0 (never the replicated edge); a shadow cast beyond the canvas is cut off. → `ObjectGoldenTests.canvasEdgeIsTransparent` (fails if the kernel uses the clamped edge)
- **Shadow Radius 0** (hard shadow), **Distance 0** (shadow centred under the object, visible only through its soft edge), **Radius 300** (kernel 601 taps; padding 502 at distance 200). → `DropShadowReferenceTests.radiusZeroHardShadow`, `ObjectGoldenTests.dropShadowGrid`, `.dropShadowRadius300`
- **Semi-transparent objects:** the shadow/outline shows through partially transparent object pixels (normal composite of the layer over the shadow). → `DropShadowReferenceTests.semiTransparentObject`, `OutlineObjectReferenceTests.semiTransparentObject`
- **Selection with object pixels outside it:** they still cast shadows/outlines into the selection; output outside the selection is untouched (FX-D). → `ObjectGoldenTests.objectOutsideSelectionCastsShadow`
- **Large radius cost:** Outline Radius 50 (8,021 taps) and Mandelbrot Quality 5 / Factor 1 are slow but progressive and cancellable. → `ObjectEffectsIntegrationTests.cancelRestoresExactly`, `RenderV1xEffectsIntegrationTests.cancelRestoresExactly`; time recorded by `RenderV1xPerformanceTests`/`ObjectPerformanceTests`
- **Hidden active layer, floating pixels, busy document, GPU unavailable / kernel missing:** 0031's framework unchanged (`.kernelMissing("juliaFractal")` etc. → "The effect couldn’t be applied.", original restored). → `CoreImageBridgeTests.kernelsLoad`, 0031 `EffectSessionIntegrationTests.rendererErrorRestores`
- **Blend list growth (0059 L-4 modes):** a `BlendMode` case without a `blend_mode_at` entry falls back to Normal on the GPU and fails `RenderV1xGoldenTests.blendStage(mode:)` — never a crash.

## Open questions

Recommended answers are applied in this spec.

1. **Fractal fidelity: the fractals are defined in IEEE single precision (`Float`) with Paint.NET 3.36's formulas, sample grid and coloring, the rotation written as `u·cos θ − v·sin θ` (mathematically identical to 3.36's `atan2`/`cos`/`sin`), and CPU-side constants — not in 3.36's `Double`.** The GPU has no `Double`, and both fractals are chaotic near the set boundary, so no `Double` oracle can be matched within ±1 by a GPU kernel; with a bit-exact `Float` iteration (safe math, no FMA contraction) the GPU matches its `Float` oracle within ±1 on every pixel (FX-B). Consequences (planner's measurement, 200×150): identical to 3.36 on stable pixels; Julia defaults differ by > 1 on 4.2 % of pixels (mean 0.28 per channel), Mandelbrot defaults on 33 % (mean 3.5) — both in the noisy boundary area, visually the same look. Paint.NET 5.0.4 also renders these "with gamma correction", which is not reproduced (all PaintDotMac effects work on sRGB bytes). Recommended: yes.
2. **Fractal frame and blending: the fractal is laid out in the reference bounds (selection bounds, else the layer — the docs: "rotates the fractal about the center of the selection or layer"; 3.36 always used the whole layer) and blended with Paint.NET 5's Blend Mode (layer bottom, fractal top, default Normal) like Clouds; 3.36 overwrote the pixel instead.** Consequence: with Normal the layer shows through where the fractal is partly transparent (Julia at defaults is mostly low-alpha), whereas 3.36 made those pixels transparent; the effect is identical to 3.36 on a transparent layer. Ranges/defaults are 3.36's (the docs give none; Paint.NET 5's dialog couldn't be inspected). Recommended: yes.
3. **Drop Shadow parameters and math: Shadow Radius 0–300 default 10, Distance 0–200 default 10, Angle −180…180 default −45 (down-right), Opacity 0–100 % default 75, Color default opaque black, Only Draw Shadow default off (Paint.NET 5 API defaults; the Distance upper bound 200 is ours because the API is unbounded); blur = Gaussian with σ = radius/3 truncated at ±radius on the layer alpha (Paint.NET 5's radius→σ mapping is unpublished); shadow alpha = blurred alpha × color alpha × opacity; the layer is composited over the shadow; the output is clipped to the selection (FX-D), although Paint.NET 5 can draw a shadow outside the selection.** Recommended: yes.
4. **Outline Object is not a Paint.NET effect** (no Paint.NET release or doc page lists it; it is BoltBait's/pyrochild's plugin, whose parameters aren't published), so PRD §5.9's requirement can't be mirrored. This spec defines it as **Radius 1–50 (default 3), Softness 0–100 (default 0), Color (default primary color)**: outline coverage = maximum over a disk of radius `R + 0.5` of the layer alpha weighted by an antialiased (Softness 0) to linear (Softness 100) falloff, drawn behind the object, rounded corners. Radius is capped at 50 because the brute-force disk maximum costs `≈ π(R+0.5)²` taps per pixel. Recommended: yes — or drop Outline Object from PRD §5.9 (then the PRD must be updated and this spec's Object submenu holds only Drop Shadow).

## Out of scope

- Paint.NET 5 effects outside PRD §5.9: Render ▸ Turbulence, Voronoi; Object ▸ Align Object; P2 effects (Fragment, Bokeh, Frosted Glass, Dents; ADJ-10).
- Gamma-correct (linear-light) rendering of any effect (*Open questions* 1).
- Shadows/outlines drawn outside the selection (*Open questions* 3).
- Any framework change (`ImageEffect`, runner, bridge, dialog); faster Outline algorithms (distance transforms) — a later performance pass may add one with the same definition.
