**Paint.NET 3.36 behavior (transcribed).** Pixel coordinates are integers `(x, y)`, y down; pixel `k`'s center is at `k` (the bilinear samplers floor the position).
- *Shared pieces.*
  - `GetRgssOffsets(quality q)`, `n = q²` samples: `n == 1` → `[(0, 0)]`; else for `i in 0..<n`: `y = (i+1)/(n+1)` (double), `x = frac(y·q)` (`x -= (int)x`), offset `((float)(x − 0.5), (float)(y − 0.5))`. q 2 → `(−0.1,−0.3), (0.3,−0.1), (−0.3,0.1), (0.1,0.3)`; q 3 → x `−0.2, 0.1, 0.4, −0.3, 0.0, 0.3, −0.4, −0.1, 0.2` with y `−0.4 … 0.4` in steps of 0.1 (a rotated-grid pattern).
  - `GetBilinearSampleClamped(u, v)`: NaN/±∞ → `Transparent`; clamp `u` to `[0, W−1]`, `v` to `[0, H−1]`; `iu = floor(u)`, 8-bit fraction `(uint)(256·(u − iu))`; right/bottom neighbor = itself at the last column/row; `BlendColors4W16IP` (alpha-weighted, truncating). `GetBilinearSample` (unclamped) is the same for positions inside `[0, W−1] × [0, H−1]`. `GetBilinearSampleWrapped`: no clamping; `sx = floor(u)` wrapped by floor-modulo (`sx < 0 → (W−1) + ((sx+1) % W)`, `sx > W−1 → sx % W`), right neighbor of column `W−1` is column 0 (rows likewise) — continuous across the seam.
  - `ColorBgra.Blend(samples, n)`: `a = ΣA / n` (truncating), color `= ΣA·C / ΣA` (truncating), `ΣA == 0` → color 0 — i.e. the premultiplied mean.
- *WarpEffectBase* (Polar Inversion). `OnSetRenderInfo`: `sel = selection bounds` (whole canvas without one); `defaultRadius = min(sel.W, sel.H)·0.5`, `defaultRadius2 = defaultRadius²`; `xCenter = sel.Left + sel.W·(1 + offset.x)·0.5`, `yCenter = sel.Top + sel.H·(1 + offset.y)·0.5` (doubles). `OnRender`, per pixel and RGSS offset `(ax, ay)` (q² samples): `td = (x − xCenter + ax, y − yCenter − ay)` (note **−ay**), `InverseTransform(td)`, `sample = ((float)(td.X + xCenter), (float)(td.Y + yCenter))`; if `0 ≤ u ≤ W−1 && 0 ≤ v ≤ H−1` (canvas size) → `GetBilinearSample`; else by `EdgeBehavior`: **Clamp** → `GetBilinearSampleClamped`; **Wrap** → `GetBilinearSampleWrapped`; **Reflect** → `GetBilinearSampleClamped(ReflectCoord(u, W), ReflectCoord(v, H))` with `ReflectCoord` = "while value < 0 { value += max; flip }; while value > max { value −= max; flip }; if flipped { value = max − value }" (period about 0 and **W**, not W−1); output `ColorBgra.Blend`. (The enum also has Primary/Secondary/Transparent/Original; Polar Inversion offers only `{Clamp, Reflect, Wrap}`, default index 2 = **Wrap**.)
- *Polar Inversion* (`WarpEffectBase`): `DoubleProperty(Amount, 1, −4, 4)`, `DoubleVectorProperty(Offset, (0,0), (−2,−2), (2,2))`, `StaticListChoiceProperty(EdgeBehavior, {Clamp, Reflect, Wrap}, 2)`, `Int32Property(Quality, 2, 1, 5)`. `InverseTransform`: `k = Lerp(1, defaultRadius2 / (x² + y²), amount)` = `1 + amount·(R²/(x²+y²) − 1)`; `(x, y) ← (x·k, y·k)`. At `x = y = 0` this is NaN ("NOTE: … will divide by zero and return NaN") → the sampler returns `Transparent`.
- *Bulge*: `Int32Property(Amount, 45, −200, 100)`, `DoubleVectorProperty(Offset, (0,0), (−1,−1), (1,1))`. **No supersampling.** `hw = W/2`, `hh = H/2` (float, **whole layer**), `maxrad = min(hw, hh)`, `amt = amount/100`; then `hw += offsetX·hw`, `hh += offsetY·hh`. Per pixel: `u = x − hw`, `v = y − hh`, `r = √(u²+v²)`, `rscale1 = 1 − r/maxrad`; if `rscale1 > 0`: `rscale2 = 1 − amt·rscale1²`, output `GetBilinearSampleClamped(u·rscale2 + hw, v·rscale2 + hh)`; else output = the source pixel.
- *Twist*: `DoubleProperty(Amount, 30, −200, 200)`, `DoubleProperty(Size, 1, 0.01, 2)`, `DoubleVectorProperty(Offset, (0,0), (−2,−2), (2,2))`, `Int32Property(Quality, 2, 1, 5)`. `amount' = −Amount`, `size' = 1/Size`; `twist = amount'²·sign(amount')` (= `−Amount·|Amount|`); `hw = W/2 + (W/2)·offset.x`, `hh` likewise (float, **whole layer**); `invmaxrad = 1/min(W/2, H/2)`. Per pixel and RGSS offset (q² samples): `u = (x − hw) + ax`, `v = (y − hh) + ay` (note **+ay**); `rad = √(u²+v²)`, `θ = atan2(v, u)`; `t = 1 − rad·size'·invmaxrad`; `t = t < 0 ? 0 : t³`; `θ += t·twist/100`; sample `GetBilinearSampleClamped(hw + rad·cos θ, hh + rad·sin θ)`; output `ColorBgra.Blend`. So pixels farther than `Size·maxrad` from the center are only resampled at the RGSS offsets.
- *Tile Reflection* (`TileEffect`): `DoubleProperty(Rotation, 30, −180, 180)` (angle chooser), `DoubleProperty(SquareSize, 40, 1, 800)`, `DoubleProperty(Curvature, 8, −100, 100)`, `Int32Property(Quality, 2, 1, 5)`. `rotation = −Angle`; `sin = (float)sin(rotation·π/180)`, `cos` likewise; `scale = (float)(π / squareSize)`; `intensity = (float)(curvature²/10·sign(curvature))`; **`q' = Quality == 1 ? 1 : Quality + 1`** (so the default 2 uses a 3×3 grid). `hw = W/2`, `hh = H/2` (float, whole layer, no center control). Per pixel and RGSS offset of `q'` (`q'²` samples): `u1 = (x − hw) + ax`, `v1 = (y − hh) − ay`; `s1 = cos·u1 + sin·v1`, `t1 = −sin·u1 + cos·v1`; `s2 = s1 + intensity·tan(s1·scale)`, `t2 = t1 + intensity·tan(t1·scale)`; `u2 = cos·s2 − sin·t2`, `v2 = sin·s2 + cos·t2`; `GetBilinearSampleWrapped(hw + u2, hh + v2)` (always wrapped); output `ColorBgra.Blend`.

## User story

As a PaintDotMac user, I open **Effects ▸ Distort** and find **Bulge…**, **Pixelate…**, **Polar Inversion…**, **Tile Reflection…** and **Twist…**. In Bulge I set the strength and drag the cross hair onto a face to swell it; in Twist I wind the image clockwise or anticlockwise around a center and choose how much of it is caught; in Polar Inversion I turn the image inside out around a point and choose whether the outside wraps, reflects or clamps; in Tile Reflection I look at my picture through a wall of curved mirror tiles at an angle. The canvas previews live, Cancel restores the image, OK adds one undoable step named after the effect, ⌘F repeats it, and with a selection only selected pixels change, with soft edges.

## Scope & changes

Cross-cutting rules (unchanged from 0031/0041/0042/0064): one file per effect conforming to `ImageEffect` with a schema, registered in `EffectRegistry.standard`; no hand-written dialog (AGENTS rule 5); every pixel change goes through 0031's `EffectSessionController` → `UndoBridge`; straight 8-bit sRGB storage, premultiplication only inside the kernels (rule 4); rendering off the main actor in 0031's runner (rule 7); selection clipping by 0031's `EffectMaskBlend` (rule 8, FX-D); `Core` imports no AppKit/SwiftUI (D-19). **No framework API change** (`ImageEffect`, `EffectRunner`, `CoreImageBridge`, `EffectRenderContext`, `EffectParameter`, `EffectOffset`, `OffsetControl`, dialog, session controller).

**Fidelity decision applied (0041's policy; *Open questions* 1):** each effect keeps Paint.NET 3.36's **geometry exactly** — the inverse transforms above, the RGSS supersampling grids (`q²`; Tile Reflection `q'²`), the `+ay`/`−ay` sign conventions, Bulge's single sample and identity outside the radius, the edge behaviors (on-surface test, Clamp, Wrap with seam-continuous neighbors, Reflect with period `W`) — but positions are computed in **Double**, bilinear sampling is **exact real-number interpolation in premultiplied space** (not 8-bit fractions), the supersamples are averaged in premultiplied space (= `ColorBgra.Blend`'s definition) and the result is un-premultiplied and **rounded to nearest** (ties away from zero). A sample whose position is non-finite, has a component with `|·| ≥ 2²⁴`, or (Polar Inversion) whose transform input is exactly `(0, 0)` contributes **(0,0,0,0)** (3.36: `Transparent`, whose alpha 0 makes it equivalent in the premultiplied mean). **Center/radius reference (*Open questions* 2):** Bulge, Twist and Polar Inversion use 0042's `.offset` (−1…1) over `EffectOffset.referenceBounds` (selection bounds, else the canvas) for the center **and** the radius (`min(W, H)/2` of those bounds) — identical to 3.36 without a selection and with offsets in −1…1; Tile Reflection keeps 3.36's canvas center. **Parameter sets = 3.36 (*Open questions* 3).**

   `reflect` equals the 3.36 loop for every input (proved in tests, including exact multiples: `reflect(2W) = 0`, `reflect(W) = W`, `reflect(−W) = W`, `reflect(3W) = W`). Edge resolution for a sample position `p` (the **definition** every oracle and kernel follows): non-finite / `≥ 2²⁴` → transparent; `isOnSurface` or `.clamp` → clamp `p` to `[0, W−1] × [0, H−1]`, bilinear with right/bottom neighbor clamped; `.reflect` → `p = (reflect(p.x, W), reflect(p.y, H))`, then as clamp; `.wrap` → bilinear on `floor(p)` with both texel indices wrapped by `wrapIndex` (so `x ∈ (W−1, W)` mixes columns `W−1` and `0`). Bilinear: `i = floor(p)`, `f = p − i`, `mix(mix(t00, t10, f.x), mix(t01, t11, f.x), f.y)` on premultiplied texels `(a·rgb, a)`, `a = A/255`.

2. **`PaintDotMac/Core/Effects/Effects/Distort/Bulge.swift`** (new).
   ```swift
   public struct Bulge: ImageEffect {
       public init()
       public let id = "bulge"; public let name = "Bulge"; public let category = EffectCategory.distort
       public var parameters: [EffectParameter] {
           [.init(id: "bulge",  label: "Bulge",  kind: .integer(range: -200...100, defaultValue: 45)),
            .init(id: "center", label: "Center", kind: .offset(defaultValue: .zero, decimals: 2))]
       }   // 3.36 order and resx labels (= the docs' names)
       public var alphaMode: EffectAlphaMode { .straight }                 // kernel premultiplies; outside the radius bytes pass through exactly
       public static func sourcePosition(x: Int, y: Int, geometry: WarpSampling.Geometry, amount: Int) -> SIMD2<Double>?   // nil = outside the radius (copy the pixel)
       public static func padding(radius: Double, amount: Int) -> Int     // min(65_535, Int((radius·|amount|/100·4/27).rounded(.up)) + 2)
       public func prepare(values:source:selection:) throws -> EffectPreparation   // amount 0 → .noChange; else geometry + padding resolved
       public func inputPadding(for values: EffectParameterValues) -> Int  // prepared _padding; missing → 65_535
       public func makeOutput(input:values:context:) throws -> CIImage
   }
   ```
   - **Definition** (oracle = this; GPU within ±1 per *Test plan*): with `(cx, cy, R)` = geometry, `amt = amount/100`: `u = x − cx`, `v = y − cy`, `r = √(u²+v²)`, `s = 1 − r/R`; `s > 0` → one sample at `(cx + u·(1 − amt·s²), cy + v·(1 − amt·s²))` with **Clamp** edges, un-premultiplied, rounded; `s ≤ 0` → the source bytes unchanged (including color under alpha 0). `R == 0` cannot happen (bounds ≥ 1×1 → `R ≥ 0.5`).
   - **Padding:** a sample moves `r·|amt|·s²` = `R·|amt|·σ(1−σ)²` (`σ = r/R`), at most `R·|amt|·4/27` (at `σ = 1/3`); +1 bilinear neighbor, +1 slack.
   - Amount 0 → `.noChange` (every in-radius sample lands exactly on its pixel, so the result is the source except that color under alpha 0 would become 0 — in 3.36 too, since `BlendColors4W16IP` zeroes color when alpha is 0; `.noChange` keeps the bytes and adds no step).
   - **`makeOutput`**: `g = WarpSampling.preparedGeometry(...)`; `try context.kernel("bulge").apply(extent: context.ciRect(context.outputRect), roiCallback: { _, r in r.insetBy(dx: -pad, dy: -pad) }, arguments: [input, CIVector(x: g.centerX, y: g.centerY), Float(g.radius), Float(Double(amount) / 100), regionVector, canvasVector])` where `regionVector = CIVector(x: in.minX, y: in.minY, z: in.maxY, w: 0)` and `canvasVector = CIVector(x: W, y: H)` (0044's pattern); nil → `EffectError.renderFailed`.

       public var alphaMode: EffectAlphaMode { .straight }
       public static func twistFactor(amount: Double) -> Double            // −amount·|amount|
       public static func sourcePosition(x: Double, y: Double, geometry: WarpSampling.Geometry, amount: Double, size: Double) -> SIMD2<Double>   // x, y = pixel + RGSS offset (+ay)

   - **Definition:** for each RGSS offset `(ax, ay)` of `quality`: `u = x − cx + ax`, `v = y − cy + ay`, `rad = √(u²+v²)`, `θ = atan2(v, u)`, `t = max(0, 1 − rad/(size·R))³`, `θ' = θ + t·twistFactor/100`, sample at `(cx + rad·cos θ', cy + rad·sin θ')`, **Clamp** edges; mean of the `quality²` premultiplied samples, un-premultiply, round.
   - **Padding:** a twisted sample stays on the circle of radius `rad` around the center, `rad < size·R` when `t > 0`, so its distance to the pixel is ≤ chord `2·size·R` plus the RGSS offset (≤ 0.71); untwisted samples move ≤ 0.71.

6. **`PaintDotMac/Core/Rendering/Shaders/EffectKernels.metal`** (extend) — under the existing `// MARK: - Distort`, shared `static inline` helpers (defined once) and four stitchable **general** kernels named after the effect ids; names appended to `CoreImageBridge`'s kernel list: `bulge`, `twist`, `polarInversion`, `tileReflection`. All trigonometry uses `precise::` functions; every texel is read at an exact texel center (filtering mode irrelevant).
   ```metal
   // region = (in.minX, in.minY, in.maxY, 0), canvas = (W, H). Canvas pixel of dest: (region.x + floor(c.x), region.z − 1 − floor(c.y)).
   static inline float4 distortTexel(coreimage::sampler src, int2 i, float4 region) {          // canvas index → premultiplied texel
       float4 s = src.sample(src.transform(float2(float(i.x) - region.x + 0.5, region.z - float(i.y) - 0.5)));
       return float4(s.rgb * s.a, s.a);
   }
   static inline float4 warpSample(coreimage::sampler src, float2 p, int mode, float2 canvas, float4 region) {
       if (!(abs(p.x) < 16777216.0 && abs(p.y) < 16777216.0)) return float4(0);              // also rejects ±inf
       int2 size = int2(canvas);
       bool on = p.x >= 0 && p.y >= 0 && p.x <= canvas.x - 1 && p.y <= canvas.y - 1;
       bool wrap = !on && mode == 1;
       if (!on && mode == 2) { p = canvas - abs(p - 2 * canvas * floor(p / (2 * canvas)) - canvas); }   // reflect, period 2W/2H
       if (!wrap) { p = clamp(p, float2(0), canvas - 1); }
       float2 f0 = floor(p); float2 f = p - f0; int2 i0 = int2(f0); int2 i1;
       if (wrap) { i0 = ((i0 % size) + size) % size; i1 = select(i0 + 1, int2(0), i0 == size - 1); }
       else      { i1 = min(i0 + 1, size - 1); }
       float4 t00 = distortTexel(src, i0, region), t10 = distortTexel(src, int2(i1.x, i0.y), region);
       float4 t01 = distortTexel(src, int2(i0.x, i1.y), region), t11 = distortTexel(src, i1, region);
       return mix(mix(t00, t10, f.x), mix(t01, t11, f.x), f.y);
   }
   static inline float2 rgssOffset(int i, int q) {                                              // Utility.GetRgssOffsets
       if (q == 1) return float2(0);
       float y = float(i + 1) / float(q * q + 1); float x = y * float(q); x -= floor(x);
       return float2(x - 0.5, y - 0.5);
   }
   static inline float4 distortStraight(float4 acc, float n) { float4 p = acc / n; return p.a > 0 ? float4(p.rgb / p.a, p.a) : float4(0); }
   ```
   - `bulge(src, float2 center, float radius, float amt, float4 region, float2 canvas, dest)`: pixel `(x, y)`; `s = 1 − length(float2(x, y) − center)/radius`; `s ≤ 0` → return the straight texel at `(x, y)` (`src.sample` at that texel center, unmodified); else `distortStraight(warpSample(src, center + (pixel − center)·(1 − amt·s²), 0, …), 1)`.
   - `twist(src, float2 center, float twistRadius, float twistPer100, float quality, float4 region, float2 canvas, dest)`: loop `q²` offsets with `+ay`; `rad`, `θ = precise::atan2(v, u)`, `t = max(0, 1 − rad/twistRadius)`, `θ += t·t·t·twistPer100`; `warpSample(…, mode 0, …)`; `distortStraight(acc, q²)`.
   - `polarInversion(src, float2 center, float radius2, float scale, float quality, float mode, float4 region, float2 canvas, dest)`: loop with `−ay`; `d2 == 0` → add nothing (transparent); else `k = 1 + scale·(radius2/d2 − 1)`, `warpSample(center + d·k, int(mode), …)`; `distortStraight(acc, q²)` (transparent samples still count in `n`).
   - `tileReflection(src, float2 sinCos, float scale, float intensity, float grid, float4 region, float2 canvas, dest)`: center `canvas/2`, loop `grid²` offsets with `−ay`, the rotate–`precise::tan`–rotate-back formulas, `warpSample(…, mode 1, …)`.
   (`f.y` weights the texel *below* in canvas space because indices are canvas indices — no CI y-flip in the math; the only flip is inside `distortTexel`.)

## Edge cases

- **Polar Inversion at the exact center** (quality 1, center on a pixel): `d² = 0` → transparent sample → output (0,0,0,0) at that pixel (as 3.36). Near the center positions explode → beyond `2²⁴` → transparent; no NaN/inf reaches a texel fetch. → `PolarInversionReferenceTests.centerPixelTransparent`, `DistortV1xGoldenTests.polarCenterFinite`
- **Scale 0** (Polar) / **amount 0** (Twist) / **curvature 0** (Tile): ≈ identity plus RGSS resampling (3.36 behavior), not `.noChange`; at quality 1 these are exact identities up to Double rounding (`PolarInversionReferenceTests.scaleZeroQuality1Identity`). **Bulge amount 0** → `.noChange` (no step, as every `.noChange` in 0033). → `BulgeTests.amountZeroIsNoChange`
- **Tile Reflection near `tan` asymptotes** (`s1·scale = π/2 + kπ`): huge but finite positions, wrapped; ≥ 2²⁴ → transparent. Ill-conditioned for GPU comparison (excluded by the conditioning mask, counted). → `TileReflectionReferenceTests.asymptoteFinite`
- **Tile Size 1 with curvature ±100** (intensity 1000): extreme aliasing, all finite; quality 5 → 36 samples. → `DistortV1xGoldenTests.extremeParametersFinite`
- **1×1 image:** every edge mode reads pixel (0,0); W−1 = 0 so clamp/wrap/reflect agree; Bulge R = 0.5. → `WarpSamplingTests.onePixelCanvas`, `DistortV1xGoldenTests.edgeSizes`
- **Odd sizes / fractional centers** (W/2 = x.5): handled in Double; 257×257 and 30×20 golden fixtures. → `DistortV1xGoldenTests.edgeSizes`
- **Selection whose bounds are 1 px wide:** radius 0.5; Bulge affects only pixels within 0.5 of the center; no division by zero. → `WarpSamplingTests.thinSelectionRadius`
- **Selection smaller than the content it samples:** samples read the whole layer (Polar/Tile reach anywhere; Bulge/Twist within their padding), only selected pixels are written. → `DistortV1xEffectsIntegrationTests.samplesOutsideSelection`
- **Transparent / semi-transparent pixels:** premultiplied interpolation and averaging; transparent samples count in the mean (alpha drops); outputs with alpha 0 are (0,0,0,0) except Bulge's pass-through pixels, which keep their bytes. → `BulgeReferenceTests.outsideRadiusKeepsBytes`, `TwistReferenceTests.alphaWeighted`
- **Empty (unallocated) layer:** all outputs (0,0,0,0) → tiles stay unallocated (0031 `blendTile` returns nil). → `DistortV1xGoldenTests.emptyLayerStaysSparse`
- **Whole-canvas padding** (Polar, Tile): each chunk reads the whole layer; slow on very large images but correct and cancellable. → `DistortV1xEffectsIntegrationTests.cancelMidRender`, `DistortV1xPerformanceTests` (informational)
- **Largest canvas side 65,535** (65,535×1): wrap/reflect indices stay in range; no overflow in `Int` conversions (positions ≥ 2²⁴ already rejected). → `DistortV1xGoldenTests.extremeAspect`
- **GPU unavailable / kernel missing:** 0031 paths (items disabled; `.kernelMissing("bulge")` → "The effect couldn't be applied.", original restored). → `CoreImageBridgeTests.kernelsLoad`

## Open questions

Recommended answers are applied in this spec.

1. **Fidelity: Paint.NET 3.36's geometry (inverse transforms, RGSS grids incl. Tile Reflection's `q+1` grid, sign conventions, Bulge's single sample and pass-through outside the radius, edge behaviors with 3.36's on-surface test, seam-continuous Wrap and period-W Reflect) in Double, with exact premultiplied bilinear sampling, premultiplied averaging and rounding to nearest — not 3.36's 8-bit-fraction bilinear and truncating blends.** Non-finite/≥ 2²⁴ positions and the Polar Inversion singularity contribute transparent samples. GPU vs oracle is ±1 on every well-conditioned pixel; pixels where the warp magnifies position error (polar center, `tan` asymptotes of Tile Reflection) are excluded from the strict comparison, counted, and capped at 2 % at defaults — because a Float GPU kernel cannot reproduce Double positions there within ±1 (FX-B's ±1 literally cannot hold at a singularity). Consequences: within ±3 of 3.36 on smooth interiors. Recommended: yes.
2. **Center and radius reference: Bulge, Twist and Polar Inversion use 0042's `.offset` (−1…1) over the selection bounds (whole canvas without a selection) for the center, and `min(W, H)/2` of the same bounds as the radius; Tile Reflection keeps 3.36's canvas center.** 3.36's Bulge and Twist ignore the selection (whole-layer center and radius) and Twist/Polar allow offsets ±2; the docs say Twist's Size "1.00 represents the entire layer or selection", 0042/0064 use −1…1 of the selection bounds (the thumbnail's reference), and extending `.offset` to ±2 would change 0042's API. Identical to 3.36 without a selection and offsets within ±1. Recommended: yes.
3. **Parameter sets are 3.36's: Bulge = Bulge + Center (single sample, clamped edges); Tile Reflection = Angle, Tile Size, Curvature, Quality (always Wrap). Paint.NET 5's documented Bulge "Edge Behavior" (Clamp, Wrap, Mirror, Transparent) and "Quality", and Tile Reflection's "Edge Behavior" (Clamp, Wrap, Reflect, Transparent), are not implemented**, because Paint.NET 5's defaults and formulas are unpublished (FX-E has nothing to take them from). They can be added later as schema parameters reusing `WarpEdgeBehavior` (a "Transparent" case would be new). Recommended: yes.
4. **Labels: Polar Inversion's strength is labeled "Scale" (the docs; 3.36's string was "Amount"), its center "Offset"; Twist uses 3.36's dialog string "Amount / Direction" (the docs write "Amount/Direction" in prose).** Sliders are linear (no exponential scaling in the 0031 schema, 0042 *Open questions* 3), with 2-decimal fields for every 3.36 `DoubleProperty`. Recommended: yes.

## Out of scope

- Paint.NET 5-only options (*Open questions* 3) and centers outside the reference bounds (*Open questions* 2).
- P2 Distort effects Frosted Glass and Dents (PRD §5.9), and Paint.NET 5's Crystalize and Morphology (not in the PRD).
- Any framework change (`ImageEffect`, runner, bridge, `.offset`/`OffsetControl`, dialog); performance tuning beyond informational measurement (a later performance pass may add bounded padding for Polar/Tile).
- Artistic, Render and Object P1 effects (0068, 0069).
